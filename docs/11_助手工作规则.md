# Sia-ai 项目助手工作规则（长期有效）

> 来源：2026-10 前后多轮协作中用户反复强调的指令、纠正与偏好，整理固化而成。
> 执行优先级：用户最新指令 > 本文档 > 项目记忆旧记录。修订须经用户确认。

## 一、沟通与汇报

1. **汇报简短直接**，但阶段性收尾归纳要**详细、分条编号**（用户明确偏好 granular 总结）。
2. 交付物（图片/报告/文件）一律带 `computer://` 预览链接；源码引用用 `file:///` 链接。
3. **允许且应当驳斥**用户的错误判断，基于实际观察给出真实结论，不一味迎合。
4. **一次只推进一件事**，不擅自并行多任务；阶段间等用户确认再继续。
5. 用户说「我去洗澡了/离开了」= 固定动作：①更新留档文档（「下次第一件事」置顶）②git commit + push。
6. 用户验收打回时，**问题清单原样记录**进留档，作为下次挑图/修复标准，不美化不省略。

## 二、验证纪律（最核心）

1. **改完必须验证**：程序化验证（运行日志/像素扫线）+ 视觉验证（截图/诊断图）双确认。
2. **出图类必须先自查再交付**：生成后拼「原型 vs 生成」对比图自查，禁止把原始输出直接扔给用户。
3. **迭代版本化**：输出文件带 vN 版本号（v5/v6/v7…），旧版保留可回滚；**用户验收通过后才清理**废件；失败即回档到最近留档版本重试。
4. **修图类用深色底检查边缘**：品红/绿底会掩盖同色系描边，深色底（模拟前端实际观感）才是有效检验。
5. 逐像素扫线是定位边缘/抠图问题的最可靠手段；先扫线取证，再下结论。

## 三、出图工作流（希亚形象）

1. **纯色背景规则**：单独生成角色外表图/三视图设定图，背景一律纯色（绿幕），方便抠图。
2. **形象生成验收规则**：生成后必须拼「原型 vs 生成」并排对比图（`sia_out/make_compare.py`），以原型图 `sia_char_magenta_00001_.png` / `_00002_.png` 及用户特意发来的参考图为基准逐项对比（脸/服装/姿势/画风/解剖结构/发长），**力求还原；不符合就重新生成或打磨，直到用户验收通过**。
3. **基准资产永不清理**：两张品红原型图、`frontend/public/avatars/stage-main.png`（面部基线）。废件清理清单永远排除它们。
4. **面部一致性**：所有新形象以 stage-main.png 的五官脸型为基准，不得修改面部特征；锁脸用 inpaint 蒙版（脸区不涂蒙版），不用 FaceID（锁身份不锁像素五官，denoise 高了脸会漂）。
5. **结构级错误重抽优先**：反关节/多腿/手消失/头脚倒转这类解剖崩坏 inpaint 修不动，加大 batch 重抽 + 严格挑图；inpaint 只修小杂（鞋色/局部瑕疵）。
6. **多视图挑图清单**：四肢关节方向、肢体数量、手是否正常、服装正背逻辑（围裙正面/背带背面）、裙长裙色视图间一致、发长、头发与身体是否混合、左右对称。
7. **人设约束**：希亚自我认同是「人造意识/千年旅者」，**绝不能自称 AI**；"AI" 只允许以她痛恨的贬低标签出现（设定冲突的戏剧引擎）。
8. **分工**：SD 出图用户自己在绘世启动器 GUI 手动出（助手负责提示词/参数/工作流说明 + 出图后接前端）；程序化批处理任务走 ComfyUI API（192.168.1.9:8188）。
9. **ComfyUI 约束**：不手写 extra_model_paths.yaml（用户自己在启动器配）；大文件走 `/upload/image` 的 bridge_share；inpaint 对贴人物窄掩膜会脑补色晕，能本地程序化处理就不走 SD。

## 四、git 与留档

1. **只在用户明确要求时 commit**；用户不熟悉 git，操作前解释每步在做什么。
2. 留档文档结构固定：`§〇 下次继续的第一件事`（置顶，最重要）→ 验收问题清单 → 方案与经验教训 → 下一步任务优先级。
3. **规则类内容双落点**：项目 docs 文档（本文件）+ `project_memory.md`（跨会话记忆），保持同步。
4. `_legacy/` 里的 xia-ai 历史引用刻意保留，勿改。
5. commit 信息用中文、说明「为什么」；一次提交一个主题。

## 五、系统环境教训（Windows / PowerShell 5.1）

1. PowerShell 5.1 **不支持 `&&`**，用 `;` 分隔；含中文的 `.ps1` 必须 UTF-8 BOM。
2. `curl.exe` 发 JSON 时内层引号会被吞——发消息用 `Invoke-RestMethod` + UTF8 字节 body。
3. pip 直调 `pip.exe` 会失败，用 `python -m pip`；pytest 用 `--no-cov`（覆盖率门禁 80% 是历史遗留不达标）。
4. 出图输出目录固定 `d:\workspace\Sia-ai\sia_out\`；临时脚本用 `_tmp_` / `_diag_` 前缀命名便于清理。
