## 三、盲听执行方案

### 3.1 测试集（固定 5 句中文 + 1 句日文对照）

| 类型 | 句子 |
|---|---|
| 陈述 | 今天夜里有点凉，记得把窗户关好再睡。 |
| 疑问 | 你今天怎么回来得这么晚？ |
| 撒娇 | 哼，人家等了你一整天了，你要好好补偿我哦。 |
| 长句 | 虽然说好了一周只见一次面，但如果每天都能像这样听你说说话，就算只是些无聊的小事，我也会觉得这一天没有白过。 |
| 短句 | 嗯，好。 |
| 日文对照（不纳入判定） | ありがとう。今日は本当に助かったよ。 |

### 3.2 合成矩阵（走产品链 POST /api/voice/tts）

- 陈述句 × 好感度 1 / 3 / 4（验证三档 ref 池联动，即 docs/23 测试计划第 4 项）
- 其余 4 句 × 好感度 3（MID 档为主听感）
- 日文对照 × 好感度 3
- 产出目录：`GPT-SoVITS/_audition/v01_accept_1030/`，mp3 命名 `{类型}_intim{档位}.mp3`
- 前置：起 api_v2（docs/20 §api_v2 用法，端口 9880）→ 起后端（8900）→ 逐句 POST

### 3.3 盲听规则

1. **先听后看分**：盲听期间不看任何机器分（CER/sim），耳朵结论先落纸
2. **70 分制**：60=能听出是合成但不忍心用 / 70=能听，有瑕疵但不破坏沉浸 / 80=几乎以假乱真。**70 分即毕业**
3. **逐句打分 + 一句话理由**（哪句最出戏、哪里最像）

### 3.4 重点听点（预埋提醒）

- 中文 mid/high 档 ref 是**评测样本（晓伊/晓晓）经摩耶 SoVITS 染色**，不是摩耶原声——判「像不像摩耶 70 分」，不判「是否完美复刻」
- 「后半句发软」问题在 TTS 路线已由能量门禁解决（0.73~0.91），耳朵复核长句后段是否依然有力
- 低档 ref（xiaoyi_c1，恶役风）与中/高档（xiaoxiao_a，温柔风）音色来源不同，三档对比时注意区分「档位差」与「质量差」
- 日文对照只确认「日文模式可用 + 摩耶原声 ref 音色更贴」，不计入 70 分判定
