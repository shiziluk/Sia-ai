## 四、关键技术结论（踩坑记录，勿重蹈）

1. **绿幕/品红幕抠图管线**：grassfire 精确局部背景场 + 边缘环 4px 最小二乘投影反混合（cutout_00002.py v7），输出前 blur 渗出区 RGB 必须用前景色场回填
2. **源图背景非纯色**：渐变/暗角偏差 24-44 → 全局背景色投影必有光晕 → 必须局部背景场
3. **诊断必须用深色底**：品红底合成会掩盖品红描边（同色相）；逐像素扫线定位边缘问题最可靠
4. ComfyUI 远程 API：`/upload/image` multipart 字段名必须为 `image`；PS 5.1 不支持 `&&` 用 `;`；git commit 多行 message 用多个 `-m`（PS 无 heredoc）
5. **img2img 三视图路线已作废**（three_view_img2img.py 留档）：
   - denoise 0.7 改不动「单人→三人并排」构图（出的还是单人）
   - **CLIP 词污染**：「green background」的 green 注意力跑到头发上 → 绿发；必须 hair 加权 `(silver hair:1.3)` + negative `(green hair:1.4)`，绿幕词改写为 `(green screen background:1.5), (chroma key backdrop:1.3)`
   - img2img 的 batch 无效：VAEEncode 的 latent batch 跟 LoadImage 单图走，需要加 `RepeatLatentBatch` 节点（txt2img 的 EmptyLatentImage batch_size=4 没这个问题）
   - denoise 0.85 理论上能让 prompt 接管构图，但人物特征漂移风险大，用户已拍板走 txt2img
6. **txt2img 绿幕成功经验**（sia_green v3，2026-10-11）：背景前置加权 + `studio even lighting` 替换暖金主光 + negative 压背景色偏离 + `(realistic human proportions:1.2)` 压头身比
7. 底图预处理（已作废但方法可复用）：竖版图等比缩到目标高、居中嵌入横版画布、两侧填背景均值色
