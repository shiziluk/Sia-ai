# 31 · 三视图迭代趋势复盘

> 建立：2026-11-01。证据：`sia_out/sia_3v_trend_review.png`，覆盖 v7、v8、v9、v10 的代表图。

## 一、结论

问题确实在减少，但不是“所有错误同步减少”。

明显改善的是：

- 视图数量从失控逐步收敛。
- 银白发色和长发连续性变好。
- 正反面围裙结构开始出现固定关系。
- 双手从消失逐步回到身体两侧。
- 双腿和鞋的基本数量、朝向更稳定。
- 背面 X 背带、腰结开始保留。

仍然反复的是：

- 围裙、短裙、裙摆和荷叶边的层叠关系。
- 侧视的胸腰臀和衣摆剖面。
- 手部细节、手指数量和手与袖口连接。
- 袜子、鞋和脚踝的一致性。
- 多视图里混入额外人物、插页或重复视图。
- 脸型和当前写实半身立绘之间的风格漂移。

## 二、批次趋势

| 批次 | 改善 | 仍存在的问题 |
|---|---|---|
| v7 | 已有多视图概念，服装配色接近 | 视图重复、透明孔洞、黑丝左右不一致、侧背结构明显漂移 |
| v8 | 白发和长发更完整，围裙正背关系开始出现 | 侧视和背视图常出现重复或额外人物，裙摆像裤装或层次断裂，手仍常消失 |
| v9 | 视图数量较稳定，黑丝双腿和背面 X 背带更常见 | 常有 5 视图、迷你插页、重复侧视；脸偏简笔，双手和衣摆仍不稳 |
| v10 | 多数收敛到 3 视图或 4 视图，手可见，腿和鞋更一致，背带结构保留 | 侧视衣摆剖面仍怪，围裙口袋/腰结不稳定，v10 00021 下摆碎条过多，脸型仍偏简笔 |

## 三、两套服装不能混判

基准原型有两个方向：

- `sia_char_magenta_00001_.png`：黑丝方向，但原图本身有一只腿缺黑丝，必须修正而不是照抄。
- `sia_char_magenta_00002_.png`：围裙/裸腿方向，花店围裙更完整。

后续模型经常把两者的服装、袜子和裙长混在一起。比较时必须先声明当前是哪一套：

- 黑丝版：双腿都必须有黑丝。
- 围裙版：双腿裸腿，不能因为看到黑丝参考就随机加黑丝。
- 两套可以共享脸、发色和体型，但不能共享错误图层。

## 四、当前可用基准

从 v10 中选：

- 正面基准：`sia_out/sia_3v10_apron_00018_.png` 的正面图。
- 透明裁切：`sia_out/sia_v10_reference/front_gold.png`。
- 选择理由：3 个视图，双手可见，腿和鞋数量完整，背面背带结构保留，围裙正面比 00016/00021 更干净。
- 明确缺口：这是围裙/裸腿版本，不是黑丝版本；侧视裙摆仍有毛病，不能当最终三视图。

`final_apron.png` 不再作为当前主基准。它来自更早的旧路线，角色观感偏娃娃，不适合作为现在“像人”的舞台源图。

> **2026-11-01 原设定复核**：v10 00018 只能当结构参考，不能当角色身份基准。它的成年感和千年旅者气质不足，默认表情偏甜软。角色优先级见 [docs/33_希亚原设定视觉核对.md](33_希亚原设定视觉核对.md)。

## 五、下一轮生成规则

1. **先选服装版本，再生成。** 黑丝版和围裙版分开跑，不混在同一次多视图。
2. **只允许 3 视图。** 正面、侧面、背面；出现 4 视图、重复侧视、迷你插页直接打回。
3. **固定手部。** 双手可见，手指可数，袖口和手腕连接正常。
4. **固定脚部。** 两只鞋、鞋底、脚踝、膝盖同一套比例；不能用裤腿代替裙摆。
5. **固定围裙拓扑。** 正面胸兜、腰结、裙身；背面只保留 X 背带和腰结。
6. **侧视必须给出衣摆剖面。** 不能用正面的衣摆直接横向拉伸。
7. **任何透明洞、碎发断片、额外人物都是硬失败。**
8. **每批和上一批并列对比。** 若问题没有减少，禁止继续抽卡，先改约束。

## 六、学习结论

这组图说明提示词在逐步起效，但剩余问题已经集中到“结构一致性”，不是颜色和风格。

下一轮不应该继续加画风词，而应该：

- 用一张参考图抽单正面。
- 不急着一次生成三视图。
- 先修正面手、鞋、围裙和脸。
- 正面通过后，再用同一张参考图分别生成侧面和背面。

这样错误不会在三视图里互相传播。
