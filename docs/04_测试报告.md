## 3. 覆盖率豁免清单及理由

豁免配置在 `backend/.coveragerc`，以下 3 个文件不计入覆盖率统计：

| 文件 | 豁免理由 |
|------|---------|
| `app/services/stt.py` | Vosk 本地识别需 2GB 中文模型（`vosk-model-cn-0.22`）与 ffmpeg 转码，单测环境无法承载 |
| `app/services/tts.py` | edge-tts 合成需访问外网微软服务，单测不依赖外网 |
| `app/db/vector.py` | chroma 首次初始化需下载 ONNX 嵌入模型（约 80MB），测试以 `FakeVector` 假实现替代其协议 |

三者的**路由层已用 mock 全覆盖**（`routes/voice.py` 100%）：TTS 服务被 monkeypatch 成功/失败两路（502），STT 被替换为正常/空串两路（422），即 HTTP 契约与错误码转换均已验证，未测的只是外部 SDK 的真实 I/O。

## 4. 测试设计说明

### 4.1 测试文件分布

| 文件 | 职责 |
|------|------|
| `tests/test_api.py` | API 集成（TestClient 走 HTTP）+ Provider 双通道 + 天气服务 |
| `tests/test_chat.py` | 对话编排：8 段 prompt、情绪检测、守卫链、流水线、日记、历史搜索 |
| `tests/test_persona.py` | 角色档案、画像、信任引擎、主动目标、欢迎语 |
| `tests/test_memory.py` | 记忆沉淀判定 / 事实提取 / 语义改写检索 |
| `tests/conftest.py` | 共享夹具（见 4.2） |

### 4.2 共享夹具（conftest.py）

| 夹具 | 机制 |
|------|------|
| 临时 `DATA_DIR` | **在导入 app 模块之前**设置 `DATA_DIR` 环境变量指向 `tempfile.mkdtemp()`，让 SQLite 引擎绑定到临时目录，测试零残留 |
| `mock_llm` | 每个测试新建 `MockProvider`（按脚本 `replies` 依次弹出，或按关键词返回可预测文本），经 `deps.override_llm()` 注入依赖，用后 `reset_overrides()` |
| `fake_vector` | 内存版 `FakeVector` 替换 `deps._vector`（实现与 `VectorMemory` 相同的 count/save/search/all_documents 协议），避免真实 chroma 初始化下载嵌入模型 |
| `client` | TestClient：每个测试 `drop_all + init_db()` 重建全部表，并将 `settings.weather_api_key` 置空以关闭天气真实外呼 |
| `db` | 干净数据库的裸会话，供 persona/chat/memory 单元测试直接操作 ORM |

## 5. 测试中发现并修复的问题

| 问题 | 影响 | 修复 | 回归测试 |
|------|------|------|---------|
| `api/routes/chat.py` 漏导入 `LLMError`（本次测试新发现） | LLM 全部通道不可用时异常未被捕获，返回 500「服务器内部错误」而非语义化的 502 | 补 `from app.providers.llm import LLMError` 并按 `except LLMError → 502` 处理 | `test_chat_llm_error_502` |
| V13 **Bug#1**：记忆事实不落日志（`saved_memory_fact` 从未赋值） | 情绪日记「我记下了」永远为空 | `remember_if_important` 返回事实文本，逐轮写入 `daily_logs.saved_memory` | `test_process_message_saves_memory_bug1` |
| V13 **Bug#2**：daily_logs 存 session_state，重启即丢 | 目标触发（依赖近 2 天日志）与日记统计失真 | 每轮落库 daily_logs，目标检查改查 DB | `test_goal_keyword_trigger` 等 |
| V13 **Bug#5**：情绪检测取 `split()[0]`，标点粘连时截断异常 | 情绪标签错乱 | `detect_emotion` 先清洗标点、限 1~4 字、异常回退「平静」 | `test_detect_emotion_*` 系列 |

## 6. 结论

- 142 个用例全绿、覆盖率 98.47%（门槛 80%），业务核心模块覆盖均在 98% 以上，达到并大幅超过质量基线；
- 测试全程离线可重复：LLM 用 MockProvider 脚本化、向量库用内存假实现、天气外呼关闭、数据落临时目录；
- 三个 V13 历史 Bug 均有回归测试锁定，本次测试阶段新发现的 `LLMError` 漏导入问题已修复并有专门用例；
- 覆盖率统计的口径（豁免清单与理由）已在第 3 节明确，路由层 HTTP 契约不受豁免影响。
