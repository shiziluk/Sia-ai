## 一、项目本体（Sia-ai）

### 1. 后端 backend（Python 3.11 + FastAPI）

```powershell
cd Sia-ai\backend
python -m venv .venv            # 必须 Python 3.11（chromadb==0.5.5 对 3.12+ 不兼容）
.venv\Scripts\activate
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

- 依赖清单已锁定在 `backend/requirements.txt`（fastapi / chromadb / ollama / edge-tts / vosk 等），不要改版本。
- **venv 不可跨机拷贝**（内部记录绝对路径），所以 F 盘里的 `.venv` 到了新电脑要删掉重建，别直接用。
- `.env` 配置：`.env.example` 是模板；涉及 API Key（在线通道 dashscope）需要用户自己填，**不在 Git 里也不建议进 F 盘明文外传**。
- 启动：`uvicorn app.main:app --reload`（或按 README）。

### 2. 前端 frontend（Vue3 + Vite + TS + Live2D）

```powershell
cd Sia-ai\frontend
npm install          # node_modules 可随 F 盘带过去，但建议删掉重装避免平台二进制差异
npm run dev
```

- Live2D 渲染靠 `@jannchie/pixi-live2d-display` + `pixi.js`（已在 package.json）。
- 模型文件（live2d 模型 assets）随仓库走，无需另下。

### 3. 出图脚本与启动参数（重要踩坑）

脚本：`sia_out/three_view_controlnet_v10.py`（API 方式提交 workflow 到 `127.0.0.1:8188`）。

**启动 ComfyUI 的正确姿势（本机实测结论，2026-10-12）：**

```powershell
python main.py --listen 127.0.0.1 --port 8188 --reserve-vram 0.5
```

- ✅ 普通模式 + `--reserve-vram 0.5`：完整跑通（4GB 显存实测）。
- ❌ **不要加 `--lowvram`**：实测必崩——加载 CLIP 到显卡时 access violation（0xC0000005）。
- ❌ 4GB 显存不要开 ControlNet union promax（加载即崩 0xC0000005，v10 脚本里已注释挂起）。
- ⚠️ 采样 30 步约 12 分钟（1440×960），崩在 VAE 解码阶段是间歇性的，重跑即可；若频繁崩，加大 `--reserve-vram` 或关掉其他吃显存程序。
- ⚠️ 日志里大量 `sageattention DLL loading error` / `0xc0000139` 是**警告非致命**，忽略。
- ⚠️ 报"页面文件太小"→ 系统虚拟内存调大到 24GB+（16GB 物理内存机器实测被咬满过）。

## 七、常见报错速查

| 报错 | 原因 | 对策 |
|---|---|---|
| `0xC0000005 access violation`（CLIP/VAE 加载时） | 4GB 显存内存抖动 + torch 2.6 Windows 驱动边缘情况 | 普通模式 + `--reserve-vram 0.5` 重启；别用 `--lowvram`；关其他吃显存程序；重跑 |
| `0xc0000139`（sageattention） | DLL 入口点不匹配 | 无害警告，忽略（自动回退 pytorch attention） |
| `页面文件太小` / `System.OutOfMemoryException` | 16GB 物理内存被 ComfyUI offload 吃满 | 虚拟内存调 24GB+；关浏览器等大内存程序 |
| ComfyUI Manager 请求失败 | 系统代理/VPN 干扰 | 关 VPN 再试 |
| HF 下载超时 | 国内网络 | `HF_ENDPOINT=https://hf-mirror.com` |
| chromadb 装不上 | Python 版本过高 | 必须 Python 3.11 |
| venv 激活后行为怪异 | F 盘拷过去的旧 venv | 删掉 `.venv` 重建 |
