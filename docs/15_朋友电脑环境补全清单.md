> 用法：按顺序执行，每步做完跑一遍「✓ 验证」。遇到报错查 §六速查表。
> 详细背景见 docs/14。最后更新：2026-10-12

## 六、报错速查

| 报错 | 对策 |
|---|---|
| `0xC0000005 access violation`（CLIP/VAE 阶段） | 用普通模式+`--reserve-vram 0.5` 重启；确认没开 `--lowvram`；关其他吃显存程序；重跑（间歇性） |
| `0xc0000139`（sageattention 一堆栈） | 无害警告，忽略 |
| `页面文件太小` / 系统 OutOfMemory | 虚拟内存调 24GB+；关浏览器等大内存程序 |
| chromadb 装不上 | Python 版本不对，必须 3.11 |
| venv 激活异常/路径报错 | 用了拷贝来的旧 venv，删掉重建 |
| ComfyUI Manager/HF 请求失败 | 关 VPN；HF 下载设 `$env:HF_ENDPOINT="https://hf-mirror.com"` |
| 采样完成但 VAE 解码崩 | 用 VAEDecodeTiled(tile_size=512)（docs/13 结论）；或直接重跑 |
| npm/pip 慢或超时 | 换镜像（npmmirror / 清华源） |
