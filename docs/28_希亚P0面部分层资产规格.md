## 三、Z-order

从下到上：

1. `face_base`
2. `eye_*_base`
3. `eye_*_iris`
4. `mouth`
5. `brow_*`（发丝下 alpha 0.55）
6. 程序化 blush / tear / mood effect

嘴和眼必须共用同一个脸部锚点，不能各自按屏幕坐标定位。

## 五、眨眼策略

当前草稿改为“完整虹膜盘整体移动”，不再按颜色只移动彩色像素：

1. 虹膜 mask 必须是完整椭圆，包含瞳孔、高光和暗边。
2. 眼底图先挖掉完整虹膜盘，再填柔和眼白色，不能保留旧瞳孔碎片。
3. 视线移动只移动虹膜盘，不移动睫毛和眼白。
4. 当前 master 位移上限收到 ±2 px；更大的位移会露出眼底修补区。
5. 后续正式版仍应补一条独立闭眼线/睫毛层。

## 六、视线策略

- 金瞳和红瞳各自由完整 iris 图层平移。
- 当前 master 位移上限 ±2 px，远眼使用 ×0.75 的增益。
- 眼白和睫毛不移动，只移动虹膜。
- 正式版仍需把 `ball` 与 `lash` 拆开；当前草稿的 eye base 仍是一整块眼周，距离生产级还有差距。

## 七、嘴型策略

- 中性嘴围绕下边界锚定，`scaleY = 0.85 + talk * 0.45`。
- `talk` 来自 TTS `AnalyserNode` RMS，范围 0..1，需平滑。
- 不移动嘴的水平中心。
- 正式版需要张嘴图；当前单嘴图只能演示纵向缩放。

## 八、表情策略

8 个 Mood 先使用参数组合：

| Mood | 原型表现 |
|---|---|
| happy | 轻微眯眼、嘴角上扬、暖色 overlay |
| sad | 视线向下、眼睑压低、冷色 overlay |
| angry | 眼睑压低、红色低透明度 overlay |
| anxious | 视线抖动、轻微缩小 |
| sleepy | 眼睑大幅压低、缓慢眨眼 |
| shy | 视线偏下、粉色 blush overlay |
| surprised | 眼睛放大、嘴微张 |
| tsundere | 半眯眼、视线偏开 |

这 8 项只是 P0 参数占位，不等于最终五官美术。

## 九、验收

- 运行 `python scripts/sia_face/check_face_layers.py`；眼部静止 MAE ≤ 5，嘴部 MAE ≤ 8。
- 异色瞳方向不能反：画面左金、右红。
- `open=1` 时叠加结果与 `final_apron.png` 的眼睛位置一致。
- 眨眼过程中不出现整张脸闪白、错位或黑块。
- 虹膜移动不拖走眼白和睫毛。
- 嘴型缩放不出现颈部或下巴拉伸。
- 刘海下的眉毛不能完全消失，也不能压住刘海。
- reduced-motion 时停止自动眨眼和呼吸，保留嘴型。

## 十、已知缺口

1. `face_base.png` 的局部 inpaint 会糊掉部分眼窝和鼻影，正式版需要手工补画。
2. 当前没拆 `ball` 和 `lash`，视线测试可能拖走眼白。
3. 当前没有正式闭眼线，眨眼闭合感只能做原型级验证。
4. 只有中性嘴，无法做真实张嘴和图元音口型。
5. 眉毛需手工擦除刘海遮挡处并补双层 alpha。

这些问题解决前，不能把本资产标成 Haru 级或正式 moc3 输入。
