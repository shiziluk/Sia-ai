# 30 · 希亚 P0 视觉翻车复盘

> 日期：2026-11-01。触发：用户打开 `prototypes/live2d-p0/?debug=1` 后，眼睛出现双瞳、空眼窝和恐怖感。

## 一、现象

- 画面左金瞳、右红瞳在移动后像脱离眼白。
- 原虹膜残片没有完全移除，和新虹膜叠成双瞳。
- 高光和深色瞳孔不属于彩色 mask，移动时只移动了一部分虹膜。
- 眼周保留的大矩形底图让移动边界更明显。
- 6px 级视线位移对这张写实半身图过大，足以暴露眼底修补。

## 二、错误判断

错误思路：

> 只要按颜色找出金色/红色像素，就能拆出 iris；其余部分用 inpaint 补。

实际错误：

1. 虹膜不是纯色像素，必须包含瞳孔、高光、暗边和反光。
2. 眼睛不是“彩色层 + 空白底”，而是眼球、睫毛、眼睑和皮肤共同构成。
3. 写实厚涂图的眼周阴影不能用低半径 inpaint 自动恢复。
4. 先做位移再看静止帧，会掩盖双瞳问题。
5. 自动 smoke test 只验证参数和画布非空，没有验证视觉接缝。
6. 可选 URL 参数用 `Number(null)` 解析，得到 0；没有传 `blink` 时反而把眼睛设成全闭。
7. 选错了源图：`final_apron.png` 是旧路线中偏娃娃感的角色表，不是当前长期基准原型。

## 三、修复

本轮改为：

- 虹膜使用完整椭圆 disk，不只取彩色像素。
- 眼底图先整体挖掉 disk，再填柔和眼白色。
- iris 位移上限从 ±6 px 收到 ±2 px。
- 原型支持 `?gaze=x,y` 复现特定视线。
- 首帧、闭眼帧、左右视线帧都必须截图检查。

同视线复现截图：`sia_out/sia_face_p0/gaze_preview.png`。

## 四、以后不再犯的规则

1. **先静帧验收，再动效验收。** 静止重叠不匹配，禁止继续调动画。
2. **移动层必须包含完整物件。** 不能用纯色 mask 代替虹膜、嘴或手。
3. **不要用 inpaint 掩盖核心遮挡。** 眼窝、鼻影、发丝遮挡必须手工补画或明确打回。
4. **参数测试不能替代视觉测试。** 非空像素、状态切换和口型数值只说明代码在跑。
5. **写实图禁止套用扁平赛璐璐比例。** 位移、挤压和变形必须按当前画风缩放。
6. **每次新增表情或动作至少检查三帧：** neutral、极值、恢复帧。
7. **恐怖谷优先归因到眼睛。** 双瞳、无神、眼白空洞、不同步都直接判定 P0 不合格。
8. **可选参数必须先判 null 再转数字。** 禁止把 `Number(query.get(...))` 直接当默认值。
9. **源图选择必须先查长期基准文档。** 希亚当前基准是 `stage-main.png` + `sia_char_magenta_00001_/00002_`；不能因为某张图同画布就拿来拆脸。

## 五、验收补充

P0 新增视觉门禁：

- 运行 `python scripts/sia_face/check_face_layers.py`；静止叠加的眼部 MAE 必须 ≤ 5，嘴部 MAE 必须 ≤ 8。
- 静止叠加与 `final_apron.png` 的眼睛 bbox 对齐。
- 视线极值时不得露出旧虹膜、皮肤洞或明显修补矩形。
- 眨眼闭合帧不得出现黑框、白洞或睫毛断裂。
- 左右眼必须同向，不出现一只看前、一只看边。
- 截图验收通过前，不得把 P0 原型接入 `frontend/src`。
