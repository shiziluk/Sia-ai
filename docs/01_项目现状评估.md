## 二、V13 功能全景（重构功能基线清单）

### 对话链路（每次发言执行）
1. 情绪检测（LLM 单标签：开心/难过/疲惫…）
2. 记忆检索：LLM 语义改写查询 → chroma 向量检索 top2 → 空结果时兜底查询 top1
3. 动态 system prompt 组装（8 段式，见下）
4. 调用 LLM 生成回复
5. 底线守卫：按亲密等级的禁止词表强拦（Level1 禁称呼"小叶/笨蛋"等）
6. 人格自检 `self_critique_response`（可开关）：等级校正 + "只是AI"傲娇反击校正 + 啰嗦拦截（>80字）+ LLM 人格一致性重写
7. 记忆沉淀：LLM 判断是否含个人信息（yes/no）→ LLM 提取 ≤20 字事实 → 入库
8. 人格状态更新：信任值 +1/轮（表白+5、开心+2），阈值 20/50/80 升级亲密度 1→4
9. 持久化：聊天记录 JSON、人格状态 JSON、当日情绪日志
10. 目标系统检查：关键词触发 + 冷却期 + 深夜限定条件

### 动态 System Prompt 8 段式
① 亲密等级行为规范（最高优先级，4 档话术规则）② 基础人设（ CHARACTER_PROFILE：傲娇腹黑/内心温柔/禁忌行为）③ 回复风格硬约束（≤5 句、≤50 字）④ 用户画像（小叶：喜恶/恐惧/关系等级/信任值）⑤ 相关记忆 ⑥ 情绪感知 ⑦ 动态行为指南（生日倒计时 0/1-3 天、雷雨关怀、情绪响应、深夜模式+哄睡、"只是AI"反击、通用规则）⑧ 今日议程（LLM 生成）

### 周边系统
- **主动目标**：`reduce_stress_weekly`（累/压力词触发，冷却 2 天）、`encourage_sleep`（23 点后+睡眠词，冷却 1 天）、`birthday_prep`（生日前 1-3 天自动激活）
- **今日议程**：LLM 根据活跃目标+近期记忆生成一句话
- **情绪日记**：当日情绪 emoji 流、高频关键词、记忆收录、深夜次数统计
- **欢迎语**：按亲密度 4 档 + 生日/雷雨/生日前夜动态选择
- **桌面通知**：浏览器 Notification（生日预提醒、雷雨安抚、超 24h 未聊想念）
- **天气联动**：和风天气 API 实时检测温州雷雨 → 通知+prompt 注入+专属欢迎语
- **语音**：输入 Vosk 中文模型（ffmpeg 转 16k WAV）+ Streamlit 录音组件；输出 edge-tts（XiaoyiNeural）
- **PWA**：manifest + sw.js + 图标（192/400/512）
- **侧边栏**：人格自检开关、好感度进度条+傲娇贴士、聊天记录搜索（日期区间+关键词）、记忆库查看、今日日记、调试按钮（清日志/重置好感/清记录）

## 四、技术债务与真实 Bug

### 架构级
1. **巨石脚本**：UI、prompt 工程、记忆、状态机、外部 API 全部混在 1223 行单文件
2. **无版本管理**：V3→V13 靠文件复制，无法回溯差异
3. **无测试、无日志**：print 调试，回归全靠手工
4. **密钥硬编码**：两处 API key 已泄漏在源码中（迁移后必须作废重发）
5. **状态三处分裂**：session_state（运行时）/ JSON 文件（半持久）/ chromadb（记忆），重启后 `daily_logs` 直接丢失

### 功能级真实 Bug（重构时修复）
1. **日记记忆永远为空**：L1243 `saved_memory_fact = None` 后从未赋值为 `clean_fact`，导致日志里 `saved_memory` 恒为 None → 情绪日记"我记下了"永远不显示
2. **daily_logs 不持久**：只存 session_state，重启丢失 → 目标触发（依赖近 2 天日志）与日记统计失真
3. **`current_mood`/`mood_streak`/`unlocked_lines` 字段从未被使用**（人格状态死字段）
4. **update_personality_state 的 `ai_response` 参数未使用**
5. **LLM 判定串噪声**：情绪检测取 `split()[0]`，qwen 返回含标点时可能截断异常

## 五、重构必要性结论

Streamlit 的"整页重跑"模型与希亚需要的**持久状态机（信任值/目标冷却/日志）**根本冲突，这是 V9→V13 每版都在和 session_state 搏斗的根因。前后端分离（FastAPI 承载状态与编排，Vue 承载展示）是唯一能同时解决：状态持久化、多端 PWA、语音链路解耦、可测试性的路径。功能不删不减，仅修上述 Bug。
